# EITN_school_2026_MFM
EITN EBRAINS Fall School in Computational Neuroscience 2026 - Mean Field Models Group

## Setup

- Download the repository as a .zip file from GitHub: open the repo page, click the green **Code** button, and select **Download ZIP**
- Extract the zip on your computer (you should get a folder like `EITN_school_2026_MFM-main`)
- Upload the entire extracted folder to the **home of your Google Drive** ("My Drive" root), without renaming it or moving it into subfolders
- Make sure the path is `/content/drive/MyDrive/EITN_school_2026_MFM-main`, so the Colab notebooks can correctly find the files (figures, data, etc.)
