## Spiking Neural Network (SNN) for the derivation of the transfer function numerical template
Wednesday 23rd (2 hours, 16:00–18:00)

- **Input:** pre-compiled BSB reconstruction of the mouse cerebellar cortex (`mouse_cerebellum.hdf5`) and circuit/simulation configuration (`circuit_Z+.yaml`)
- **SNN simulation** (BSB–NEST, EGLIF neurons): raster, PSTH and firing rates of each population, used as reference activity for MFM validation (Day 4)
- **Numerical transfer-function template** for Zebrin+ Purkinje cells: NEST-based stimulation of a single EGLIF postsynaptic neuron over a 2D grid of presynaptic rates (GrC × MLI)
- **Exercise:** templates for the other populations (Golgi cells: 3D template)
